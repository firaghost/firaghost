<details>
<summary>⚙️ Self-host stats cards (~20 min, one-time setup)</summary>
<br/>

The public instance is rate-limited — self-host your own:

1. `github.com/settings/tokens` → Tokens (classic) → Generate new → tick `repo` → No expiration → copy immediately (never paste publicly)
2. Fork [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats)
3. [vercel.com](https://vercel.com) → Sign up with GitHub → Hobby (free) → New Project → import fork
4. Add env var: `PAT_1` = your token → Deploy
5. Replace `YOUR-INSTANCE` above with your `your-instance.vercel.app` URL

</details>
